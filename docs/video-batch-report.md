## 3. 关键发现

1. **素材标签不匹配是最大瓶颈** — 58% 的 clip 为 "general" 未重新打标签
2. **美食类视频几乎全 fallback** — 云南素材库缺美食类镜头
3. **时长稳定** — 所有视频 19-34s 范围，短视频规格达标
4. **配音稳定** — 20 条全成功，Edge TTS 可靠
5. **字幕全部生成** — Whisper base 模型可用但识别偶有错字
