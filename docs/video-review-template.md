# AI Travel Video Factory — 视频质量评估模板

用于人工审片时标准化评分。每个维度 10 分，总分 50 分。

---

## 评分卡

| 维度 | 满分 | 评分标准 |
|------|------|----------|
| 文案质量 | 10 | 口语化、有节奏、信息密度适中、吸引力 |
| 配音质量 | 10 | 语音自然度、语速、情绪匹配、清晰度 |
| 素材匹配 | 10 | 画面与文本的语义对应、场景切换合理性 |
| 剪辑节奏 | 10 | 时长分配、画面变速流畅度、视觉疲劳度 |
| 字幕体验 | 10 | 准确性、断句合理性、可读性、时间同步 |

---

## 评分细则

### 文案质量 (0-10)

| 分数 | 描述 |
|------|------|
| 0-3  | 不通顺、信息错误、大量重复 |
| 4-6  | 基本通顺但平淡、缺乏亮点、AI感明显 |
| 7-8  | 通顺自然、有节奏变化、适合短视频 |
| 9-10 | 引人入胜、有情感共鸣、口语化完美 |

### 配音质量 (0-10)

| 分数 | 描述 |
|------|------|
| 0-3  | 机械感重、咬字不清、语速失控 |
| 4-6  | 基本可听但生硬、情绪平淡 |
| 7-8  | 自然流畅、情绪适度、无AI痕迹 |
| 9-10 | 有感染力、情感丰富、类似真人播音 |

### 素材匹配 (0-10)

| 分数 | 描述 |
|------|------|
| 0-3  | 大面积 fallback、画面与文案无关 |
| 4-6  | 部分匹配、多数场景有相关镜头 |
| 7-8  | 画面与场景描述较一致、氛围匹配 |
| 9-10 | 精准匹配、场景切换自然、视觉叙事强 |

### 剪辑节奏 (0-10)

| 分数 | 描述 |
|------|------|
| 0-3  | 画面停滞过长、或切换过于频繁 |
| 4-6  | 节奏大体可接受、部分场景时长不对 |
| 7-8  | 节奏合理、画面信息量适中 |
| 9-10 | 专业级剪辑节奏、有节奏变化 |

### 字幕体验 (0-10)

| 分数 | 描述 |
|------|------|
| 0-3  | 识别严重错误、覆盖不全、无法阅读 |
| 4-6  | 基本可读但部分错误、断句不当 |
| 7-8  | 准确率较好、断句合理、稍有瑕疵 |
| 9-10 | 准确、断句完美、时间同步精准 |

## 通过/不通过标准

| 总分 | 判定 |
|------|------|
| 40-50 | **优秀** — 可作为产品展示 |
| 30-39 | **合格** — 可发布但需微调 |
| 20-29 | **待优化** — 至少 1 个维度需要改进 |
| 0-19  | **不可发布** — 需要大幅改进 |
