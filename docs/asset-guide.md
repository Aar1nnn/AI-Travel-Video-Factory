# 素材库维护指南

## 目录结构

```
assets/
├── index.json      # 素材索引（本文件是核心）
├── airport/        # 机场/交通类
├── hotel/          # 酒店/住宿类
├── island/         # 海岛/海滩类
├── food/           # 美食/餐饮类
├── sunset/         # 日落/黄昏类
├── jungle/         # 丛林/自然类
└── general/        # 通用素材（标题背景、转场、兜底）
```

## 添加新素材

1. 将图片/视频放入对应的子目录
2. 运行 `python main.py --scan-assets` 重新生成索引
3. 为新素材添加标签：`python main.py --tag asset_XXX --add "标签1,标签2"`
4. 如果素材是视频，`scan-assets` 会自动探测时长

## 标签规范

- 使用中文标签
- 标签应具体、可检索
- 每个素材建议 3~8 个标签
- 标签类型建议覆盖：
  - **内容** — 画面里有什么（日落、海滩、美食）
  - **地点** — 拍摄地点（沙巴、东京、曼谷）
  - **氛围** — 画面感觉（浪漫、活力、宁静）
  - **用途** — 适合什么场景（开场、结尾、转场）

## 素材来源

- 自有拍摄
- Pexels / Pixabay / Unsplash（免费商用）
- 标注 `source` 字段以便追溯版权
