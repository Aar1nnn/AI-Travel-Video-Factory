## 4. 按优先级汇总需求

### 高优先级素材（必须填补）

```
# 地点覆盖
沙巴全景、亚庇地标、云南全景、东京全景

# 地标
东京塔、浅草寺、雷门、大理古城、玉龙雪山、神山公园

# 自然
滇池、洱海、新宿御苑、红叶、丹绒亚路日落、美人鱼岛、红树林

# 城市
涩谷十字路口

# 美食
海鲜市场、筑地市场

# 氛围
情侣牵手、情侣相拥、海岛俯瞰

# 住宿
丽江民宿
```

### 中优先级素材（建议填补）

```
长鼻猴、萤火虫、滑翔伞、ATV、海鸥、小电驴、骑行、
民谣、酒吧、情侣背影、手办店、女仆咖啡厅、海鲜丼、
台场高达、霓虹灯、仲见世通、伴手礼、银座、歌舞伎町
```

### 低优先级

```
芝士、小奶牛、扭蛋机、行李箱、飞机（可用通用素材代替）
```
