# Phase 3 — 瓶颈分析 & 优先级

**日期**: 2026-06-08
**数据来源**: 20 条批量生成的云南旅游视频
**分析方法**: 基于真实生成结果，人工抽样 + 统计

---

## 瓶颈排序（影响视频质量从高到低）

### P0 — 素材标签匹配率（影响最大，当前 25-50%）

**问题**: 94 个 clip 中 55 个 (58%) scene_type 为 "general"。CLIP auto-tag 只覆盖了 39 个旧 clip，新处理的 55 个 clip 未标注。LLM 生成的精细标签（如 "独克宗"、"松赞林寺"、"烤乳扇"）无法命中通用标签。

**证据**: 云南美食攻略 6/6 场景全 fallback。香格里拉 3/5 场景 fallback。

**修复方式**:
- 对所有 94 个 clip 运行 `--auto-tag`
- 扩展中文标签词库覆盖云南专属名词

**预期提升**: 命中率 25% → 60-80%

---

### P1 — 素材库内容单一（所有素材来自同一个视频源）

**问题**: 94 个 clip 全部来自 `疆域.mp4` 和 23 个其他视频的切分。素材内容偏航拍/自然风光，缺少:
- 美食特写
- 古城街道
- 人文活动
- 室内场景
- 夜景

**证据**: 美食类、民宿类、市场类主题几乎全 fallback。

**修复方式**:
- 下载 Pexels/Unsplash 云南特定关键词素材
- 按 SceneType 分类补全

---

### P2 — 智能剪辑节奏（当前按字数均分时长）

**问题**: 每个 scene 的时长按 `字数/总字数` 比例分配。这导致:
- 短句可能分配到太短的 clip（<2s 出现突兀切换）
- 长句分配到过长的单个 clip（>8s 视觉疲劳）

**证据**: 平均时长 12.1s 的 clip 被分配给 2-3 秒的配音片段，画面跟不上语音。

**修复方式**:
- 场景内多素材渐变切换
- asset_duration 按 tag 匹配度而非均分

---

### P3 — 文案质量（LLM 文本不稳定）

**问题**: DeepSeek 生成的文本偶有长度异常（<80 字或 >200 字），需要 LLM 重试（5/20 次）。

**证据**: 云南亲子游和云南摄影攻略都触发了 LLM 重试。

**修复方式**:
- 优化 Prompt 增加长度约束
- 增加后处理裁剪/补充逻辑

---

### P4 — 字幕质量（Whisper base 模型有错字）

**问题**: Whisper base 模型对中文的识别有拼音化错误，如 "大理"识别为 "大礼"。

**证据**: 抽样 subtitles.srt 可见多处同音错字。

**修复方式**:
- 升级到 medium 模型（本地可用）
- 或对已有 script.text 做强制对齐而非纯语音识别

---

### P5 — 剪辑流畅度（缺少转场）

**问题**: 连续画面之间无过渡效果，画面之间硬切。

**修复方式**:
- 添加简单 crossfade (FFmpeg 可做)

---

## 优先级总结

| 优先级 | 模块 | 对视频质量影响 | 改动量 | 建议时间 |
|--------|------|---------------|--------|----------|
| **P0** | 素材标签匹配 | 
| **P1** | 素材库内容多样性 | 
| **P2** | 编辑节奏优化 | 
| P3 | 文案质量 | 
| P4 | 字幕质量 | 
| P5 | 转场效果 | 

**结论: 接下来应该集中改进素材标签系统，而不是增加新功能模块。**
