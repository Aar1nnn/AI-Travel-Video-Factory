# 素材库标准 (Asset Standard)

本文档定义 AI Travel Video Factory 素材库的文件命名、标签、分类、
格式和质量标准。所有素材导入和维护操作必须遵守此标准。

---

## 1. 目录结构规范

素材按 **国家 → 城市/地区 → 类别** 三级层级组织：

```
assets/
├── index.json                    # 自动生成，不手动编辑
├── malaysia/
│   └── sabah/
│       ├── island/               # 海岛类
│       ├── sunset/               # 日落类
│       ├── food/                 # 美食类
│       ├── hotel/                # 酒店类
│       ├── jungle/               # 丛林/自然类
│       └── airport/              # 机场/交通类
├── china/
│   └── yunnan/
│       ├── lijiang/              # 丽江
│       ├── dali/                 # 大理
│       ├── kunming/              # 昆明
│       └── shangri-la/           # 香格里拉
├── japan/
│   └── tokyo/
│       ├── urban/                # 城市景观
│       ├── temple/               # 寺庙/神社
│       ├── food/                 # 美食
│       ├── shopping/             # 购物/商业
│       └── nature/               # 自然/公园
└── general/                      # 通用素材（不限地域）
    ├── transitions/              # 转场素材
    ├── backgrounds/              # 背景素材
    └── overlays/                 # 叠加素材
```

### 规则

1. **国家目录**: 英文小写，空格用连字符（如 `new-zealand`）
2. **城市目录**: 英文小写，空格用连字符（如 `kuala-lumpur`）
3. **类别目录**: 英文小写，使用标准类别名
4. **不允许**: 直接在 assets/ 根目录放素材文件
5. **特殊情况**: 通用素材（不限地点）放 `general/`

---

## 2. 文件命名规范

### 格式

```
{描述}_{序号}.{扩展名}
```

### 规则

1. **描述**: 英文小写字母，单词间用下划线分隔
2. **序号**: 2 位数字，从 01 开始（如同一场景多张图）
3. **禁止**: 中文、空格、特殊字符、大写字母

### 示例

```
✅ correct:
  manukan_aerial_01.mp4
  sensoji_temple_main_01.jpg
  lijiang_old_town_street_01.jpg
  tokyo_shibuya_crossing_night_01.mp4

❌ wrong:
  沙巴海滩.mp4                  (中文)
  Manukan Aerial.mp4            (空格 + 大写)
  2024-03-15_IMG_4321.jpg       (无意义编号)
  sunset(1).jpg                 (括号)
```

## 3. 标签规范

### 标签结构

每个素材至少 **5 个标签**，最多 **12 个标签**，覆盖以下四类：

| 维度 | 说明 | 示例 |
|------|------|------|
| **内容** | 画面里有什么 | 海滩、寺庙、美食、樱花 |
| **地点** | 国家/城市/区域 | 沙巴、东京、云南 |
| **氛围** | 画面感觉 | 浪漫、活力、宁静、震撼 |
| **用途** | 适合什么场景 | 开场、结尾、转场、B卷 |

### 标签命名规则

1. 使用中文描述标签
2. 标签长度 1~8 个中文字符
3. 不使用特殊符号
4. 避免过于宽泛无法检索的标签（如"好看"、"风景"）

### 标准标签词库（建议优先使用）

```
# 地点标签
沙巴、亚庇、东京、云南、大理、丽江、昆明、曼谷、京都、大阪

# 内容标签
海滩、日落、海岛、城市、寺庙、神社、樱花、枫叶、雪景、
美食、夜市、市场、购物、温泉、城堡、花园、博物馆

# 氛围标签
浪漫、活力、宁静、震撼、温馨、神秘、高级、治愈

# 用途标签
开场、结尾、过渡、B卷、竖屏封面、旅行Vlog
```

## 4. 素材分类规范

### 标准类别 (category)

每个素材必须属于以下标准类别之一：

| 类别 | 说明 | 适合场景 |
|------|------|----------|
| `aerial` | 航拍/俯瞰 | 开场吸引、地理展示 |
| `landscape` | 自然风光 | 意境铺垫、空镜 |
| `urban` | 城市街道/建筑 | 城市旅行、人文氛围 |
| `food` | 美食/餐饮 | 美食特写、夜市探店 |
| `cultural` | 文化/宗教/历史 | 寺庙、博物馆、民俗 |
| `hotel` | 酒店/住宿 | 住宿体验 |
| `transport` | 交通/出行 | 机场、火车、过渡 |
| `activity` | 活动/体验 | 浮潜、骑行、滑雪 |
| `wildlife` | 动物/生态 | 长鼻猴、萤火虫、樱花 |
| `sunset` | 日落/日出 | 浪漫氛围、结尾 |
| `night` | 夜景/灯光 | 城市夜景、夜市 |
| `generic` | 通用素材 | 转场、背景、兜底 |

## 5. 视频格式规范

| 属性 | 最低要求 | 推荐 |
|------|----------|------|
| **分辨率** | 1920×1080 (横屏) / 1080×1920 (竖屏) | 4K 3840×2160 |
| **帧率** | 24 fps | 30 fps |
| **编码** | H.264 | H.264 / H.265 |
| **容器** | MP4 | MP4 |
| **时长** | 3~60 秒 | 5~30 秒 |
| **码率** | ≥ 5 Mbps (1080p) | ≥ 10 Mbps |
| **音频** | 可选 | AAC 立体声 |
| **竖屏素材** | 必须已有竖屏版本或可裁剪区域 | 原生竖屏拍摄 |

---

## 6. 图片格式规范

| 属性 | 最低要求 | 推荐 |
|------|----------|------|
| **分辨率** | 1920×1080 (横屏) / 1080×1920 (竖屏) | ≥ 2000px 宽边 |
| **格式** | JPEG / PNG | JPEG (质量 85+) |
| **色彩** | sRGB | Adobe RGB |
| **文件大小** | ≤ 10 MB | ≤ 5 MB |
| **竖屏图片** | 宽高比 9:16 | 原生竖屏 |

## 7. index.json 结构规范

```json
{
  "id": "asset_001",
  "path": "malaysia/sabah/island/manukan_aerial_01.mp4",
  "type": "video",
  "country": "malaysia",
  "city": "sabah",
  "category": "aerial",
  "tags": ["海岛", "俯瞰", "玻璃海", "沙巴", "浮潜", "跳岛"],
  "duration": 12.5,
  "resolution": "1920x1080",
  "orientation": "horizontal",
  "file_size_kb": 8450,
  "source": "自有拍摄",
  "license": "own"
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | ✅ | 自动生成，格式 `asset_NNN` |
| `path` | string | ✅ | 相对于 assets/ 的路径 |
| `type` | string | ✅ | `image` 或 `video` |
| `country` | string | ✅ | 国家目录名（小写英文） |
| `city` | string | ✅ | 城市目录名（小写英文） |
| `category` | string | ✅ | 标准类别（见 §4） |
| `tags` | string[] | ✅ | 标签列表（见 §3） |
| `duration` | float | 视频 | 视频时长（秒），图片为 null |
| `resolution` | string | 自动 | `WxH`（自动检测） |
| `orientation` | string | 自动 | `vertical` 或 `horizontal` |
| `file_size_kb` | int | 自动 | 文件大小（KB） |
| `source` | string | 推荐 | 来源标注 |
| `license` | string | 推荐 | `own`、`pexels`、`unsplash`、`pixabay` |

## 8. 素材质量标准

### 内容质量
- [ ] 画面清晰、无模糊
- [ ] 曝光正确、无过曝/欠曝
- [ ] 画面稳定（视频无剧烈抖动）
- [ ] 构图合理、主体突出
- [ ] 无遮挡、无污点、无水印

### 竖屏适配
- [ ] 主体在画面中间区域（竖屏裁剪后不丢失核心内容）
- [ ] 或者已有竖屏裁剪版本

### 版权合规
- [ ] 来源标注准确
- [ ] 商用许可确认
- [ ] 不包含可识别的人脸（除非有授权）
